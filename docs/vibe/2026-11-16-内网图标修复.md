# 内网图标修复

内网模型管理页的厂商图标和默认头像请求外网失败。用户已确认采用本地资源方案：厂商及知识库图标随网页打包，默认头像在浏览器生成。仅修改 Web，不增加依赖、不修改数据库或模型参数，保留用户上传头像。

## 实施与验收

- [x] 先用回归测试确认旧代码依赖外网，再修复模型、知识库图标路径。
- [x] 默认头像生成独立 SVG 图片地址，同一 ID 结果固定，不请求头像服务。
- [x] 远程容器执行相关测试、Web 检查和生产构建。
- [ ] 仅更新远程 Web，浏览器阻断外网验证模型管理、智能体与头像显示；清理临时资源。

内网线上由用户传包更新，远程开发环境验收不代表内网线上已更新。

## 验证记录

- 旧代码：资源测试因图标使用外网 URL 失败，头像测试因依赖 DiceBear URL 失败；真实浏览器禁用缓存并阻断外部 HTTPS 后，模型管理页 22 张图片中有 21 张加载失败。
- 修复后：新增资源测试通过，20 个 SVG 合计 24,394 字节；完整 Web 测试共 13 项通过（包括头像的 8 组断言），ESLint 全量检查通过。
- 远程生产镜像构建成功；构建仍有现有依赖的 PURE 注释和较大代码块提示，本次未修改依赖或构建设置。
