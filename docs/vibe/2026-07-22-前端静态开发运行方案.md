# 前端静态开发运行方案

## 目标

解决 Web 与 chat-iframe 在开发联调时因 Vite HMR WebSocket 失联而整页刷新、丢失页面内存状态的问题，并保持正式环境的静态部署边界。

## 验收标准

- 默认开发 Compose 的 Web 与 chat-iframe 均由 Nginx 提供 Vite 构建产物，不加载 HMR 客户端。
- chat-iframe 开发 Compose 只读挂载示例页和测试附件，生产镜像继续移除这些调试资源。
- 后端源码挂载和热重载行为不变。
- 前端修改通过重建 `web`、`chat-iframe` 服务生效。

## Checklist

- [x] 开发 Compose 切换到静态前端运行阶段。
- [x] chat-iframe 在开发 Compose 中只读挂载示例资源。
- [x] 增加运行模式回归检查。
- [x] 同步开发说明和变更记录。
