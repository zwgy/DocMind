# MinerU 独立部署

## 目标与范围

- 复用官方 `docker/mineru/mineru.Dockerfile` 构建完整 MinerU 镜像。
- 从项目主 Compose 抽出单服务 `docker/mineru/mineru-compose.yaml`，使整个 `docker/mineru` 目录可复制到联网内网电脑独立部署。
- 不接入 GPUStack 模型服务；GPUStack 只与 MinerU 共享物理 GPU 主机。
- 通过 Nginx 暴露一个固定宿主机端口，MinerU 仅在 Compose 内网监听；后续应用使用不同路径复用该端口。
