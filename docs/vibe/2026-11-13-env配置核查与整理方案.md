# .env 配置核查与整理方案

日期：2026-11-13。核查基线：main@0580b37e。状态：用户已批准，模板和初始化脚本已实施，远程部署验收中；实际既有配置和发布包保持原样。

## 结论

通用模板的 71 项参数混合了启动配置、可选功能、构建输入和其他部署方式。离线脚本原样复制模板，再由 init 生成 .env.prod，导致无关参数一起出现。应按使用场景整理模板；必需项保留，当前可选项注释，失效入口删除，其他场景参数移出离线模板。

关键问题不只有注释：开发初始化把 SILICONFLOW_API_KEY 视为必填，与内网自建模型不符；旧 OCR 变量已失效；部分沙盒变量在离线编排中已被固定值或实例名替代；现有配置文档声称所有系统配置都能由环境变量覆盖，也不符合当前 Config(BaseModel) 的实际读取方式。

## 核查方法和范围

- 覆盖 .env.template 全部 71 项（含注释项），逐项检查项目已跟踪的源码、Compose、Dockerfile、初始化和打包脚本。
- 对照 main 的实际离线应用包：15 个服务，无 build 段，无 MinerU/PaddleX 服务。仅选用相应解析器时读取可选 OCR 服务配置。
- 区分字面量读取、Compose 映射和供应商 api_key_env 的动态读取，不能仅凭字符串无命中判定无用。
- 不读取或复制真实密钥，不改实际 .env、.env.prod、sandbox.env 和业务数据。本次未运行本机 Docker。
- 本清单聚焦公开模板及部署相关缺项，不声称列出了项目所有诊断环境变量。

## 分类口径

“启动必须”不等于人工填写：七个生产密钥/标识由 init 自动生成。“业务必须”包括模型地址、模型 ID、凭据和默认 OCR 选择，主要在网页设置，不应伪装成 .env 必填。“按需注释”表示功能和入口仍有效，使用该功能时再启用。

| 配置 | 处理 |
| --- | --- |
| COMPOSE_PROJECT_NAME、WEB_PORT | 离线入口必须能看到，默认 docmind、80；同机实例不同名不同端口 |
| POSTGRES_URL、POSTGRES_USER、POSTGRES_DB | 包内数据库已有默认值；外部数据库需要另行设计连接与内置服务处理，不顺带改成本次默认 |

## 整理方案与取舍

推荐最小改动：通用开发/联网构建模板继续作为参数参考；新增一份手工维护的生产运行模板，脚本明确选择模板，离线打包使用该运行模板。只在确有联网构建或额外 profile 使用时，按文档向配置追加对应构建/可选服务参数。

不采用继续整份复制再按变量名删除的方式：以后新增参数仍容易漏删，且会把“没有匹配到”误当作“没有用途”。不增加配置注册器、自动迁移、模板继承或运行环境配置平台。

拟改动范围：

1. .env.template：按开发必需、可选功能、联网构建分组；删除旧入口；保留当前开发端口行为。
2. 新增 .env.prod.template：仅保留生产运行所需和少量有效的可选项，说明模型与 OCR 去网页配置。联网构建输入不混入首次运行配置。
3. scripts/manage.sh 与 scripts/manage.ps1：生产从 .env.prod.template 初始化；移除针对特定云供应商的询问；生成七项密钥/标识。已存在 .env.prod 原样保留。
4. scripts/init.sh 与 scripts/init.ps1：把硅基流动密钥改为可选，写入逻辑能在注释项原位置启用，不制造重复项；现有值不覆盖。
5. scripts/offline/prepare_compose.py：使用生产运行模板生成包内 .env.prod.template，并追加仅离线有效的 COMPOSE_PROJECT_NAME、WEB_PORT；不再复制通用 .env.template，不提供旧模板名回退。
6. 同步配置说明、离线部署说明、README、变更记录及初始化/离线行为测试。不改模型、OCR、沙盒、数据库的业务实现。

模板生效关系保持直白：开发 .env.template → .env；生产 .env.prod.template → .env.prod；离线包携带同名的生产模板，并追加离线入口项，deploy.sh init 调用同一生产初始化入口。现有源码生产编排将网页端口固定为 80，且容器名固定；WEB_PORT 与按项目名隔离多实例仅在离线生成编排中有效，本次不顺带扩展源码生产编排能力。

## 预期生产运行模板的主要内容

以下是结构示意，不包含真实密钥，详细默认值在实施时按既有行为核对。

```dotenv
# 部署入口；模式由生产 Compose 固定，不用于切换成开发运行。
YUXI_ENV=production
COMPOSE_PROJECT_NAME=docmind
WEB_PORT=80

# 初始化自动生成，首次启动后不要随意替换。
JWT_SECRET_KEY=
YUXI_INSTANCE_ID=
SANDBOX_PROVISIONER_TOKEN=
POSTGRES_PASSWORD=
NEO4J_PASSWORD=
MINIO_ACCESS_KEY=
MINIO_SECRET_KEY=

# 填实际业务系统来源；* 只适用于第一项。留空含义不同，见说明。
YUXI_CORS_ORIGINS=
CHAT_IFRAME_ALLOWED_ORIGINS=
# CHAT_IFRAME_TOKEN_RATE_LIMIT_PER_MINUTE=60

# 模型地址、ID、维度和默认模型去网页设置；凭据也可在网页填写。
# 如供应商选择“环境变量凭据”，填写对应变量名并取消下一行注释。
# INTRANET_MODEL_API_KEY=

# 当前沙盒默认值无需填写；确需调整才取消注释。
# SANDBOX_EXEC_TIMEOUT_SECONDS=180
# SANDBOX_MAX_OUTPUT_BYTES=262144
# SANDBOX_KEEPALIVE_INTERVAL_SECONDS=30
# SANDBOX_IDLE_TIMEOUT_SECONDS=120
# SANDBOX_IDLE_CHECK_INTERVAL_SECONDS=10
# SANDBOX_HTTP_PROXY=
# SANDBOX_HTTPS_PROXY=
# YUXI_URL_WHITELIST=
```

来源限制默认值属于需要明确说明的调整：现有通用模板的 iframe 列表是 localhost 开发地址，生产不应沿用它。拟使用空值并明确其含义为“不检查换票来源”；若希望默认限制来源，应在首次部署填写实际业务系统地址。不得把空值描述为关闭换票功能。
