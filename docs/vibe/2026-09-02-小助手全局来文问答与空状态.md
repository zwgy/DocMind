# 小助手全局来文问答与空状态

## 目标

当接入方没有传入页面内容和页面来文时，小助手仍应明确提示用户可以查询后端已收录的来文；提示中承诺的检索、解读、原文查看和文件下载能力必须真实可用。

## 范围

- 来文可按标题、文号、发文单位、时间、分类、结构化条目类型和通用关键词检索。
- 通用关键词覆盖标题、文号、发文单位、已生成摘要和附件名称，不承诺全库附件正文检索。
- 搜索结果按来文日期稳定排序，准确区分主文件和附件数量；附件名称在用户选定来文后随详情完整展示。
- 列表检索命中多份时直接展示分页结果；只有用户要求操作单篇来文且目标不唯一时才要求选择。
- 用户选定来文后可查看摘要、结构化关键信息和指定附件的 Markdown 原文。
- 用户可下载指定来文的原始主文件或附件，文件通过当前会话产物链路交付。
- 来文与知识库 Skill 分别正向描述自身能力，不通过互相点名或通用沙箱路径特判控制模型路由。
- 复杂的多步骤或交付物任务由通用 Agent 使用 Todo/ReAct 编排；来文工具只提供有界、确定性的领域操作。
- 流程图工具保持严格拓扑校验，同时在边引用错误时返回无效边和有效节点 ID，帮助小模型在模块内修正参数。
- L5 摘要完整但略超目标时只允许一次有界压缩修复；修复后仍超限、被截断或丢失精确事实时保持原子失败。
- 无页面来文但有页面内容时，欢迎区提示可询问当前页面。
- 页面内容和页面来文均无时，欢迎区说明全局来文能力，并提供两个仅回填输入框、不自动发送的示例问题。

## 验收标准

- [x] 搜索与统计工具接受标题、文号和发文单位筛选，通用关键词覆盖约定字段。
- [x] 普通聊天可通过内置来文 Skill 查找来文，并继续读取摘要和结构化关键信息。
- [x] 指定附件可按需写入当前线程目录供原文核验。
- [x] 指定原始主文件或附件可作为会话产物预览或下载，且不暴露 MinIO 地址和宿主机路径。
- [x] 有页面内容、无页面来文时显示页面问答提示。
- [x] 页面内容和页面来文均无时显示全局来文能力及两个示例问题；点击后只回填并聚焦输入框。
- [x] 后端单元测试、chat-iframe 测试、类型检查、Lint 和构建通过。
- [x] 来文原文定位由来文领域工具返回条款边界，通用沙箱不包含来文专属判断。
- [ ] 复杂办公产物真实对话会制定并更新 Todo，失败时调整计划，验证交付物后结束。
- [ ] 流程图错误反馈可指导模型修正节点 ID 和顶层输出名称，连续错误触发的 L5 摘要可在一次有界修复后继续。
- [ ] 使用远程已有真实来文补验标题片段、空结果、多结果分页、主文件与多附件查看/下载，以及基于来文的办公产物场景。
