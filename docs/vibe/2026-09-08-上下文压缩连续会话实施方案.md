# 上下文压缩连续会话实施方案

**目标：** 摘要超时、空响应、截断、超限或事实校验失败不再中断会话；历史可追溯，当前请求和工具协议保持完整。

**设计依据：** 用户已确认的“确定性收缩保证连续性，语义摘要提升记忆质量”方案。本文件取代 2026-07-31 方案中“摘要失败立即结束、不允许无摘要收缩”的旧约束。

**技术栈：** Python 3.12、LangChain/LangGraph、现有线程文件后端、Docker Compose。

## 边界

- 在现有压缩控制器和纯消息投影模块中实现，不添加领域 Skill 特判、新服务或新数据库表。
- 完整历史与发送给模型的活动视图分开。归档成功后才提交消息收缩；归档失败时保留原检查点，只投影本次请求。
- 不吞掉取消信号、不重放工具、不将主模型故障伪装为成功。
- 部署窗口必须能容纳基本系统指令及最新请求的可读入口；固定配置故障保留明确诊断。
