## 本轮修正

- 生产 Compose 增加 Scheduler、Dispatcher，复用 API 镜像、生产连接配置和数据库健康依赖，具备进程心跳检查及优雅停止时间。新增回归测试曾在原配置下失败，补齐后通过。
- 摘要流测试将模拟模型窗口改为可容纳完整摘要协议的大小；Worker 启动测试改在配置类上替换同步方法，保留原有全部业务断言，生产逻辑未因此放宽。
- 数据集恢复接口的测试夹具先检查身份，再初始化连接资源，并在结束后关闭连接池、复位初始化标志。原夹具在凭据跳过后仍遗留连接任务，独立复现可阻塞进程退出；修正后正常跳过退出，另用真实 PostgreSQL 资源核验关闭和重新初始化均成功。
- 来文错峰测试原用固定的 2026-09-07 时间认领当前登记的任务，早于 `next_attempt_at`。改用数据库当前时间构造下一次上海时间 07:29:59 和 07:30:00，保留窗口外不得执行的断言。
- 修正生产源码的三项 Ruff 问题，仅涉及未用导入、长行换行，不改变行为。
- 分支维护规则写入[贡献指南](../develop-guides/contributing.md)，以其为长期规则来源。
