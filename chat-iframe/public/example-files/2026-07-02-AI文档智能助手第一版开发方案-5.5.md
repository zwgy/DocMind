### 5.5 附件 DOM 识别

生产系统附件示例：

```html
<div class="items">
  <div class="item" id="xxx_BOX" attachment="xxx">
    <a href="###" onclick="YZSoft.File.download('http://10.132.235.62:8082/YZSoft/Attachment/dafault.ashx?xxx')">
      <span class="flag"></span>
      "新车函（2026）162号.pdf"
      <span class="size">-200.16KB</span>
    </a>
  </div>
</div>
```

父页面脚本采集规则：

1. 优先扫描 `.items .item[attachment] a`，再降级扫描页面中的 `a` 元素。
2. 从 `textContent` 中移除 `.size` 文本，去掉外层引号，得到文件名。
3. 从 `.size` 或完整文本中提取大小，支持 `-200.16KB` 这类无空格格式。
4. 从 `onclick="YZSoft.File.download('...')"`、普通 `onclick` 和 `href` 中提取 URL。
5. 按 `attachment` 属性、`id` 去掉 `_BOX` 后缀、URL query、路径片段的顺序提取 `sourceKey`。
6. 文件名后缀命中文档扩展名时加入附件列表。
7. 第一个附件标记为默认选中。

支持扩展名：

```text
doc, docx, pdf, xls, xlsx, ppt, pptx, txt, md, csv
```
